# Как подключить GigaChat API с нуля

---

## Шаг 1 — Регистрация

1. Зайдите на [developers.sber.ru](https://developers.sber.ru).
2. Нажмите значок меню **☰** в правом верхнем углу.
3. Нажмите **Войти** и авторизуйтесь через Сбер ID или по номеру телефона.

---

## Шаг 2 — Создание проекта

1. После входа нажмите **Создать проект** → **GigaChat API**.
2. Примите пользовательское соглашение.
3. Введите название проекта.
4. Нажмите **Создать**.

---

## Шаг 3 — Тариф

1. Выберите тариф **Физическое лицо**.

> 💡 На старте есть бесплатный лимит, банковская карта не нужна.

---

## Шаг 4 — Получение ключа

1. Откройте созданный проект.
2. Найдите раздел **"Настроить API"**.
3. В блоке **Authorization Key** нажмите **Получить новый ключ** и скопируйте строку.

---

## Шаг 5 — Ключ в приложении

1. Откройте WordZap → **Настройки** → поле **API-ключ ИИ**.
2. Вставьте скопированный ключ и нажмите **Сохранить**.

---

## Шаг 6 — Выбор модели

В **Настройках** под ключом есть поле **Модель ИИ**. Рядом с каждой моделью приложение показывает, сколько токенов для неё осталось.

| Модель | Какая |
|---|---|
| **GigaChat 2 Lite** | быстрая и самая экономная, выбрана по умолчанию |
| **GigaChat 2 Pro** | умнее, лучше следует инструкциям |
| **GigaChat 2 Max** | ещё умнее, для сложных задач |
| **GigaChat 3 Ultra** | новейшая и самая умная |

> 💡 Для примеров и переводов слов хватает **Lite**. Для проверки ответов в уроках лучше **Pro**: она реже ошибается в оценке.

> ⚠️ Токены заканчиваются. У каждой модели свой остаток, и чем умнее модель, тем быстрее он тратится.
